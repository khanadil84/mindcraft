# MindCraft Game Design Contract

Every generated game design must contain:

## 1. Game Identity
- Game title
- Short description
- Core objective

## 2. Gameplay
- Player controls
- Main mechanic
- Win condition
- Lose condition

## 3. World
- Player
- Enemies or hazards
- Collectibles or targets
- Boundaries

## 4. Technical Requirements
- Browser playable
- HTML5 Canvas or DOM
- Vanilla JavaScript
- No external runtime dependencies
- Single self-contained HTML file

## 5. Playtest Requirements
The generated game must expose enough predictable behavior to verify:
- The game loads successfully
- Player input works
- The main mechanic works
- Collision/boundary logic works where applicable
- Win/lose conditions can be reached
- No uncaught JavaScript errors occur
